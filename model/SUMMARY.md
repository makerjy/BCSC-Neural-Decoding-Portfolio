# EEG 음소 디코딩 — 결과 정리

`npz2` 파이프라인 (0–1.0s, 256Hz, 16명 × ~208시행 = 3328). 상세 기록은 `RESULTS.md` 11절,
스크립트 지도는 `SCRIPTS.md`. 코드는 `model/`에 있다 (`model/README.md`).

**한 줄**: 자기 데이터가 있는 사람에 대해 11음소 0.305 (우연 0.091), 표준 딥 베이스라인 대비
동일 폴드 15/15승 p=2e-8. 미학습 피험자에게는 어떤 모델로도 동작하지 않으며, 그 이유가
정량화됐다 — 피험자 간 판별방향 공유가 3% 이하.

## 2. 모델 구조

### 2.1 `model/final_model.py` — 통제를 통과한 부품만 (설계본)

```
X (61채널 × 256샘플)
 │
 ├ STAGE 1  필터 : 신호대잡음 최대화 공간 투영   61 → 14
 │    S_phon  = Σ_s Σ_c (M_sc − M_s)(M_sc − M_s)ᵀ        피험자 내 클래스 간 = 신호
 │    S_noise = Σ_s Σ_c Σ_i (x_i − M_sc)(x_i − M_sc)ᵀ    피험자·클래스 내 잔차 = 잡음
 │    W = eigh(S_phon, S_noise + εI) 상위 14열,  Z = Wᵀ X
 │
 ├ STAGE 2  베이스 모델 : 시행당 SPD 하나 (변 36 = 14 + 14 + 8)
 │    A(t) = [ Z(t) ; Z(t−20) ; φ₀(t) … φ₇(t) ]        φ = 직교 DCT, unit RMS
 │    C = A Aᵀ / T      중심화 안 함 (φ행이 유발 파형을 붙잡게)
 │       Z×Z        → 공간 공분산
 │       Z×Z(t−τ)   → 선형 교차지연 = 동역학
 │       Z×φ_k      → 각 모드 파형의 k번째 DCT 성분 = 시간분해 유발반응
 │    → log-Euclidean 접선 → 상삼각 666차원
 │
 └ STAGE 3  판독 : 접선공간 가우시안, 피험자별 결정규칙
```

### 2.2 최고 성능 모델 (`model/best_concat.py`, 라플라시안 61모드 6밴드)

몽타주 그래프 라플라시안 고유모드를 공간주파수 순으로 6밴드 분할 (`[0:10]…[50:61]`),
밴드마다 표현을 만들어 concat.

| 이름 | 밴드당 표현 | 차원 |
|---|---|---|
`band_blocks` | 지연증강 공분산 접선 + 창4 공분산 접선 + 창4 평균 | 2911 |
`band_one` | 통합 SPD (지연 + DCT 시간 기저), 변 28 | 2495 |
`band_one+blocks` | 위 둘 concat — **앙상블이며 설계가 아니다** | 5406 |
`global_one` | 밴드 없이 단일 통합 SPD, 변 36 | 666 |

### 2.3 EEGNet-8,2 베이스라인 (`model/eegnet.py`)

`Conv2d(1→8,(1,128))` → `Depthwise(8→16,(61,1))` → `Separable(16→16)` → `Linear`.
max-norm 제약, Adam 1e-3, ≤200 epoch, 내부 검증 early stop.
arm: `persubj` / `pooled` / `pooled+subjbias` / `pooled+ft_head` (trunk 동결 + head 재적합).

11클래스에서 raw 정확도는 오해를 만들므로 `(acc − 0.091)`을 EEGNet 최고로 나눈 비를 함께 둔다.

`per-subject`는 공유된 특징 공간 위에서 피험자마다 분류기 하나(그 피험자 훈련 시행으로만 적합,
피험자별 값의 평균), `pooled`는 같은 공간에 전체 하나의 분류기다. 특징 공간(기저·접선 기준점·
스케일러)은 두 경우 모두 훈련 폴드에서 공유하므로 차이는 판독뿐이다.
`final_model` 수치는 10폴드 기준이며, 5폴드로는 0.252였다 (`--study den`, `--study perm`).

**차원과 파라미터 수**

| 모델 | 분류기 입력 차원 | 어디서 나오는가 |
|---|---|---|
`final_model` | 666 | 변 36 = 14(Z) + 14(Z 지연) + 8(φ) → 상삼각 36·37/2 |
`band_one` | 2495 | 밴드 6개(모드 10·10·10·10·10·11) → 변 28~30 → 406×5 + 465 |
`band_blocks` | 2911 | 밴드마다 지연증강 접선 210 + 창4×(공분산 55 + 평균 10) = 470, 마지막 밴드 561 |
`band_one+blocks` | 5406 | 2495 + 2911 |
EEGNet | 128 | flatten 직전. **학습 파라미터 4,011개** (전 피험자 공유) |

두 계열은 파라미터 개념이 다르다. EEGNet은 4,011개를 경사하강으로 학습한다. `final_model`은
공간 필터 854 + 접선 기준점 666 + 스케일러 1332을 전원 공유로 추정하고, 그 위에 피험자별로
클래스 평균 11×666과 클래스내 공분산 666·667/2를 추정한다(명목 합계 약 3.7M). 다만 후자는
경사하강 가중치가 아니라 **Ledoit-Wolf로 강하게 수축된 닫힌 형태 2차 추정치**이고 공분산은
클래스 간·(pooled일 때) 피험자 간 공유되므로, 실효 자유도는 명목값보다 훨씬 작다. 숫자를 직접
비교하지 말 것.

**EEGNet 대비 짝지은 검정** (동일 폴드 15개):
`band_one+blocks` 0.305 vs `pooled+ft_head` 0.225 → **+0.080, 고전이 15/15 승, p = 2e-8**.

`band_one+blocks`는 `band_blocks` 대비 per-subject +0.017 (p=0.0017), pooled +0.026 (p<1e-4).
`band_one`은 per-subject에서 −0.019 (p<1e-4)로 지고 pooled에서는 동률 (+0.003, p=0.51).

### 3.3 한 번도 만지지 않은 최종 test셋 (`model/holdout.py`)

세션의 모든 숫자는 그것이 측정된 폴드에서 선택됐다. arm 열 개를 같은 폴드에서 비교하고 최고를
헤드라인으로 냈으므로 낙관 편향이 있다. 시행 20%를 seed 12345로 떼어 **선택에 한 번도 쓰지 않고
모델당 정확히 한 번만** 채점했다 (dev 2662 / final 666).

| 모델 | 차원 | dev (inner CV) | **final** (미접촉) |
|---|---|---|---|
`band_one+blocks` | 5406 | 0.257 ± 0.007 | **0.306** |
`band_blocks` | 2911 | 0.249 ± 0.011 | 0.283 |
`band_one` | 2495 | 0.224 ± 0.003 | 0.272 |
`final_model` | 666 | 0.220 ± 0.011 | 0.245 |
`global_one` | 666 | 0.204 ± 0.008 | 0.232 |

**inner CV가 고를 모델과 final 실제 최고가 같다** (`band_one+blocks`), 순위도 5/5 일치.
**선택 편향 = +0.000.** CV 숫자 0.305와 미접촉 0.306이 사실상 동일하다.

final은 단일 측정이므로 오차가 있다: 666시행·클래스당 60–61에서 **SE ≈ 0.018, 95% CI
[0.271, 0.341]** (피험자별 평균이라 실제로는 조금 더 넓다).

**남는 한계**: 이것은 *모델 선택* 편향만 검증한다. `d=14 · K=7 · τ=20 · bands=6 · windows=4 ·
den=noise`는 dev와 겹치는 폴드에서 이미 고른 값으로 고정했으므로 재검증되지 않았다. 완전히
깨끗하게 하려면 그 격자까지 dev 안에서 훑어야 한다.

바로잡았다 — 대칭으로 놓으면 ph11 LOSO는 0.139 대 0.139로 완전히 동률이다.

## 4. 통제 감사 — 각 부품이 주장한 이유로 작동하는가

정확도가 올라간 것과 주장한 메커니즘이 작동한 것은 다르다. 부품마다 **동일 차원·동일 규모로
메커니즘만 파괴한 대조군**을 만들어 재었다.

### 4.1 통과 ✅

**시간 기저 (φ 행)** — 통합 객체 안에 시간 순서를 넣는다는 주장. `arch.py --study phi`, 10폴드:

| φ 변형 | 차원 | persubj | vs `dct_low` |
|---|---|---|---|
**`dct_low`** (k=0..7) | 666 | **0.237** | — |
`none` (행 없음) | 406 | 0.185 | −0.052 (p<1e-4) |
`shuffled` (시간축 고정 치환) | 666 | 0.184 | −0.054 (p<1e-4) |
`gauss` (구조 없음) | 666 | 0.172 | −0.066 (p<1e-4) |
`dct_high` (k=40..47) | 666 | 0.136 | −0.101 (p<1e-4) |

차원 효과가 아니고, 아무 행이나도 아니고, 시간 척도가 맞아야 한다. `dct_high`가 `none`보다도
나쁜 것은 φ행이 "추가 특징"이 아니라 SPD 객체의 기하를 바꾸며 척도가 틀리면 오염시킨다는 뜻이다.
`K_time` 용량-반응도 역U를 그린다: K=0/1/3/7/15/23 → 0.171/0.191/0.214/**0.231**/0.222/0.206.
K=7은 1.01초 창에서 최고 성분 ≈3.5Hz — N1/P2 유발복합체의 시간 척도.

**정확도와 독립인 확인 하나** (`slides/make_figs.py`). 절제는 "빼면 떨어진다"를 보이지만
"어느 블록이 정보를 담는가"는 직접 보이지 않는다. 판독이 실제로 보는 양 — 피험자 중심화 후
`log(C)`의 **항목별 F = 클래스간 분산 / 클래스내 분산** — 을 블록별로 평균하면:

| 블록 | 평균 F |
|---|---|
`Z × Z` (공간) | 1.59 |
`Z × Z(t−τ)` (동역학) | 1.35 |
**`Z × φ` (유발)** | **2.99** |
**`Z(t−τ) × φ`** | **2.76** |
`φ × φ` | 2.10 |

**φ 교차항이 공간 블록의 약 두 배**다. 주의할 점 하나 — 원시 클래스간 *분산*으로 재면 φ 블록은
거의 0으로 보인다(절대 크기가 작다). 분류기가 쓰는 것은 절대 분산이 아니라 클래스내 분산 대비
비율이고, 그 척도에서만 설계가 정당화된다.

**지도 공간 투영** — 고정 기저(`lap_band`) 대비 +0.016 (p=0.016), 동일 rank 랜덤 투영 대비
+0.018 (p=0.005).

**SNR 분모** — 이론이 먼저 정한 선택(센서공간 LDA)이고 측정이 동의: 0.252 vs `eye` 0.235.

**개인 판독** — EEGNet `pooled+ft_head`가 `persubj` 대비 +0.044 (p=0.0001), 반면 단순 `pooled`는
+0.009 (p=0.23, ns). 선형 모델과 딥 모델이 같은 구조에서 같은 결론에 도달한다.

### 4.2 축소 ⚠️

**라플라시안 기저** — "해부학적 좌표계"라는 주장은 반증됐다. 동일 61차원 직교회전 4종:

| 기저 | ph11 persubj | ph11 pooled | cv persubj |
|---|---|---|---|
`lap` | 0.287 | **0.208** | 0.753 |
`pca` | 0.281 | 0.187 | 0.752 |
`chan` (몽타주 순서) | 0.248 | 0.181 | 0.724 |
`rand` (랜덤 회전) | 0.253 | 0.190 | 0.724 |

이득은 해부학이 아니라 **스케일 정렬** (+0.033). `chan`이 대략 앞뒤 해부학 순서인데도 `rand`와
같다. 살아남는 약한 버전: pooled에서 `lap`이 `pca`보다 +0.021 — 적합 없는 고정 기저라 16명이
문자 그대로 같은 축을 쓰는 효과가 pooled에서만 값을 한다.

**접선 기저 자체가 최적이 아니다** (`model/spdnet.py`, 15폴드). 접선공간에 **고정 랜덤 직교회전**
하나를 먹이면 설계본을 이긴다: 0.255 vs 0.248, **+0.007, 95% CI [+0.001, +0.014], p=0.035,
11/15.** 회전은 정보를 바꾸지 않는다 — 고유값이 그대로고 특징은 직교변환일 뿐이다. 이기는 이유는
`lda_persubj`가 회전 불변이 아니기 때문이다: StandardScaler가 좌표마다 스케일을 재고 Ledoit-Wolf가
그 결과의 단위행렬 쪽으로 수축하므로, **어느 방향이 정규화될지를 기저가 결정한다.** 4.2의
라플라시안 결과와 같은 모양이고, 이번엔 대상이 설계본 자신이다.

필터는 작동하지만 주장한 이유로는 아니다. 피험자 억제도 기하 매끄러움 prior도 기여 0이고,
피험자 억제 단독은 최악이다. 이유는 4.4와 정합한다 — `cos_b ≈ 0.01`이면 "피험자 분산은 저쪽,
공유된 음소 부분공간은 이쪽"이라는 분리가 존재하지 않으므로, 피험자 간 방향을 투영 제거하면
개별 피험자에게는 바로 그 방향이 자기 음소 신호를 담고 있다.

**비선형 지연 동역학** — 통합 객체는 전부 2차 선형 통계다. `Z×Z(t−τ)`는 선형 DDE가 남기는
2차 지문이지만 `a₃x(t−τ)²`는 보이지 않는다. 넣어서 재었다 (`nonlin.py`, 990차원 동일):

| rows | persubj | vs `real` |
|---|---|---|
~~`shuffled_LEAKY`~~ | ~~0.267~~ | +0.028 — **라벨 누수, 버림** |
`none` (현재 객체, 666차원) | **0.244** | +0.005 (p=0.24) |
`linear` (2차 대신 선형 행) | 0.243 | +0.004 (p=0.42) |
`real` (2차 지연 행) | 0.239 | — |
`shifted` (시행 내 지연 관계 파괴) | 0.238 | −0.001 (p=0.87) |
`shuffled` (다른 시행의 지연 사본) | 0.234 | −0.005 (p=0.32) |

라벨을 쓰지 않는 통제 셋이 전부 `real`과 구분되지 않는다. `linear`도 `none`과 같으므로 용량
문제도 아니다. 이로써 비선형 동역학 부재는 **네 번째** 독립 확인이다 (앞선 셋: DDA a₃ 중앙값
0.00004 = a₁의 1/1000 · R²=0.009, 뉴런 6종 전부 동일, 리저버 ρ=0.5 ≈ 1.3). 이유는 표본 수다 —
2차 모멘트도 shrinkage 없이는 208시행으로 추정이 안 되는데 3차 모멘트를 볼 SNR은 없다
(단일시행 |d| ≤ 0.98).

**리저버 계보 전체** — 두 결과를 함께 봐야 뜻이 통하고, **둘의 근거 강도가 다르다.**

*(1) 견고한 쪽.* 두피 라플라시안 W는 동일 조건(ρ·leak·비선형성 일치) 랜덤 W를 **+0.0235로
이긴다 — 15/15 폴드, 95% CI [+0.015, +0.032], p<1e-4.** 매칭이 잘 된 비교이고, **재귀 연산자에
기하를 넣는 것 자체는 작동한다.**

*(2) 약한 쪽.* "리저버가 지연 임베딩에 보태지 못한다"는 결론 방향은 맞지만 **자주 인용된
−0.019는 판독을 갈아탄 숫자다.** `onemodel_rescomb.log`의 같은 표에서:

| 표현 | hier2 | **persubj** | pooled |
|---|---|---|---|
`one_KT` | 0.236 | 0.231 | 0.181 |
`res_lap+one_KT` | 0.217 | 0.228 | 0.182 |
| 차이 | −0.019 (p<1e-4) | **−0.003** | **+0.001** |

−0.019는 **hier2 열**이고 **최종 모델이 쓰는 판독은 persubj**다. 정확한 진술은 *"붙여도 늘지
않는다(persubj −0.003, pooled +0.001), 계층 판독에서만 해롭다"*이지 *"−0.019로 해롭다"*가 아니다.

여기에 통제 결함 둘이 더 붙었었다. **(a) 단일 설정** — ρ=0.90·leak=0.30·gain=1.00·tanh 하나만
돌렸고 front-end도 production(`snr_filter`)이 아니라 `basis=pca d=14 lo=20`이었다. **(b) 재실행
불가** — 코드를 제거했었다.

**→ `model/reservoir.py`로 다시 세워서 넷 다 해소했다** (이 절 아래 "역전파 없는 연결주의"
항목). 결론은 유지되지만 이제 근거가 단일 셀이 아니라 27개 셀의 용량-반응 곡선이다.

generalized synchronization도 성립할 수 없다. GS는 attractor를 가진 구동계와 초기조건을 씻어낼
긴 washout을 요구하는데, 시행은 256샘플짜리 일회성 임펄스 응답이고 **정보가 있는 부분이 바로
그 초기 transient**다. 측정된 서명도 정합한다 — 뉴런 종류와 ρ가 모두 null인 것은 리저버가
동기화가 아니라 저역통과 필터링을 하고 있을 때의 모습이다.

**τ (지연)** — 5/10/20/40 → 0.233/0.227/0.231/0.238. 평평하다. 이전 15개 변형이 τ=20으로
고정했던 것은 결과적으로 문제가 아니었다.

**같은 기하 안에서의 연결주의적 창발** (`model/spdnet.py`, ph11 15폴드). EEGNet 비교는
설계-vs-학습과 SPD-vs-유클리드를 한꺼번에 바꾸므로 무엇이 이겼는지 분리하지 못한다. 기하를
고정하고 **학습되는 양만** 바꿔 다시 쟀다 — SPDNet의 BiMap/ReEig/LogEig를 역전파로 학습시킨다.

| arm | 무엇이 학습되나 | 판독 | ph11 | vs 설계본 |
|---|---|---|---|---|
`rand_rot` | 없음 (고정 랜덤 회전) | 고전 | **0.255** | +0.007 (p=0.035) |
`designed` | 필터만 (닫힌 형태) | 고전 | 0.248 | — |
`spdnet` | 표현 (BiMap 36→24→16) | 고전 | 0.232 | **−0.016 (p=0.003), 2/15** |

`spdnet` | 표현 | 자체 softmax | 0.180 | −0.067 |
`spdnet_e2e` | 필터 + 표현 | 자체 softmax | 0.180 | −0.068 |

**표현을 학습하면 진다. 앞단까지 학습하면 더 진다.** 판독을 맞추기 위해 두 줄로 잰다 — 네트의
LogEig 특징을 `sdcore.lda_persubj`에 그대로 태운 `+고전` 줄이 설계본과 바이트 단위로 같은
판독이므로, 그 차이는 순수하게 표현의 차이다. 네트 자체 softmax가 0.180으로 크게 지는 것은
**pooled 대 개인 판독 결론이 학습 모델 안에서 재현된 것**이다 (4.1 개인 판독 항목과 같은 방향).

차원을 보존하는 정사각 BiMap은 설계본을 이긴다 (0.256 vs 0.248, p=0.042, 11/15). 그러나
**학습 없는 랜덤 회전과 완전히 같다**:

| | ph11 (15폴드) | vs 설계본 |
|---|---|---|
학습된 정사각 회전 | 0.256 | +0.0077 (p=0.042, 11/15) |
**랜덤 정사각 회전** | 0.255 | +0.0073 (p=0.035, 11/15) |
| 학습 − 랜덤 | | **+0.0005, CI [−0.004, +0.005], p=0.84, 7/15** |

CI가 ±0.005로 좁으므로 이건 "유의하지 않다"가 아니라 **"기여가 없다"**이다. 차원을 보존하는
다양체 층에서 역전파가 랜덤 회전 이상으로 얻는 것은 없고, 이득은 전부 기저의 조건수에서 온다
— 위 4.2 항목.

→ 이로써 "창발이 안 되는 것은 딥이라서가 아니라 표본이 없어서"라는 주장이 유클리드 CNN 하나가
아니라 **기하를 건네준 모델에서도** 성립한다. 남은 반론은 표본 수뿐이다 (피험자당 208시행,
클래스당 ~19).

**역전파 없는 연결주의 — 리저버 재측정.** `spdnet.py`는 표현을 **학습**시키면 어떻게 되는지를 물었다. 그건 표현이 **창발**하면 어떻게
되는지와 다른 질문이다. 연결주의는 경사하강을 요구하지 않는다 — 리저버 컴퓨팅은 재귀 가중치를
랜덤으로 고정하고 판독만 맞춘다. `model/reservoir.py`에는 역전파가 한 줄도 없다.

구조는 리저버를 **동일한 파이프라인 앞에** 끼우는 것이라, `designed`가 "리저버를 뺀 것"이 아니라
**항등 리저버**다 (a=1, W=0, f=항등, W_in=I → r(t)=x(t)). `--selftest`가 `max|R−X| = 0`을
확인하므로, 다른 숫자는 배관이 아니라 동역학에 귀속된다.

**스윕 26셀 + designed, 5폴드** (`logs/reservoir_sweep_ph11.log`). designed = 0.252.

| ρ \ 비선형 | tanh | relu | linear |
|---|---|---|---|
0.3 | 0.233–0.237 | 0.216–0.222 | 0.236–**0.245** |
0.9 | 0.227–0.230 | 0.211–0.213 | 0.207–0.223 |
1.3 | 0.197–0.209 | 0.175–0.181 | 0.096–0.152 (1개 발산) |

전부 진다. 중요한 건 그게 아니라 **모양**이다. 스펙트럼 반지름이 커질수록 단조 감소하고,
비선형성은 도움이 안 되며(linear ≥ tanh > relu), **최적 셀이 ρ=0.3 · leak=1.0 · linear** —
약한 재귀, 적분 기억 없음, 비선형성 없음이다. **최적점이 "리저버가 없는 쪽" 모서리에 앉아 있고,
거기서도 없는 것에 진다.** 크기도 같은 방향이다: N = 61 → 0.245, 122 → 0.214, 244 → 0.218 —
이 방법의 요체인 고차원 확장이 오히려 해롭다.

concat의 CI가 ±0.006이므로 이건 "못 잡았다"가 아니라 **"보태는 게 없다"**이다. 게다가 최적 셀은
채점 폴드와 겹치는 폴드에서 골랐으므로 **선택 편향을 리저버 쪽에 남겨둔 채**로 재고 있다 —
가설 쪽으로 판을 기울여 놓고도 진다.

**기하 주장은 재현되고 오히려 좋아졌다.** 옛 셀(ρ=0.9·leak=0.3·tanh)에서 `res_lap` 0.251 vs

"리저버를 쓸 값어치가 있다"는 죽는다.** 그 격차가 셀에 의존하는 것도 정합적이다 — ρ=0.9/tanh에서
+0.021인데 ρ=0.3/linear에서 +0.003이다. ρ=0.3·leak=1.0이면 재귀가 거의 작동하지 않으니 W의
구조가 통과할 통로가 없다.

4절의 항목별 집계: **통과 4** (시간 기저 · 지도 공간 투영 · SNR 분모 · 개인 판독),
**축소 2** (라플라시안 기저 · 접선 기저), **반증 6** (필터의 피험자/음소 분리 · 비선형 지연
동역학 · 리저버 계보 · τ · 피험자 통합 · 기하 내 연결주의적 창발).

또한 **라벨 누수 2건**을 잡았다: 오늘 클래스 짝맞춤 대리변수(+0.028 부풀림), 그리고 과거
hyperalignment (0.991 → 0.531).

## 7. 코드 배치

`model/`에는 **모델 3개와 그것을 평가하는 코드만** 둔다.

| | 파일 | 무엇인가 |
|---|---|---|
① | `model/eegnet.py` | 베이스라인 EEGNet-8,2 |
② | `model/final_model.py` | **메인 모델.** 통제를 통과한 부품만 (3.3의 0.245) |
③ | `model/best_concat.py` | 최고 성능. 표현 두 개 concat (3.3의 0.306), 설계가 아닌 앙상블 |
| | `model/sdcore.py` | 공유 라이브러리. 세 모델이 여기서만 import |
| | `model/holdout.py` | 세 모델을 미접촉 test셋에서 비교, 선택 편향 측정 |
| | `model/spdnet.py` | 통제 실험. 기하를 고정한 채 설계 vs **학습** (4.3), `--selftest` 내장 |
| | `model/reservoir.py` | 통제 실험. 역전파 없는 **창발** — 리저버 27셀 스윕 (4.3), `--selftest` 내장 |

4절의 통제 연구를 만든 스크립트는 `attic/studies/`에 있다 (`arch`, `nonlin`, `contrast`,
`budget`, `geom`, `hier`, `hier2`, `onemodel`, `synth`). 모델이 아니라 "부품이 주장한 이유로
작동하는가"를 재는 실험이라 분리했다. 실행법은 `attic/studies/README.md` — 공유 라이브러리가
`model/`에 있으므로 `PYTHONPATH=model`이 필요하다.

## 8. 재현

```bash
# 모델 (model/)
python model/holdout.py     --task ph11                  # 세 모델 미접촉 test셋 비교
python model/final_model.py --task ph11 --study split    # 네 분할 전부
python model/final_model.py --task ph11 --study perm     # 라벨 순열 귀무
python model/final_model.py --task ph11 --study adapt    # 라벨 없는 재중심화 (LOSO)
python model/final_model.py --task ph11 --study readout  # per-subject vs pooled
python model/best_concat.py --task ph11 --study split
python model/best_concat.py --task ph11 --study perm
python model/eegnet.py      --task ph11 --seeds 3
python model/eegnet.py      --task ph11 --split loso     # + 라벨없는 BN 적응

# 기하를 고정한 설계 vs 학습 (4.3)
python model/spdnet.py --selftest                        # torch 구현을 sdcore와 대조
python model/spdnet.py --task ph11 --arms designed rand_rot spdnet spdnet_e2e --seeds 3
python model/spdnet.py --task ph11 --arms spdnet --ladder 36 --seeds 3   # 차원 보존 회전

# 역전파 없는 창발 (4.3) — 리저버
python model/reservoir.py --selftest                     # 항등 리저버 = designed 확인
python model/reservoir.py --task ph11 --study sweep       # ρ×leak×비선형성 27셀 + N
python model/reservoir.py --task ph11 --study geom --seeds 3               # res_lap vs res_rand
python model/reservoir.py --task ph11 --study main --rho 0.3 --leak 1.0 --nl linear --seeds 3

# 통제 연구 (attic/studies/, 공유 라이브러리가 model/에 있어 PYTHONPATH 필요)
PYTHONPATH=model python attic/studies/arch.py     --task ph11 --study phi
PYTHONPATH=model python attic/studies/arch.py     --task ph11 --study filter
PYTHONPATH=model python attic/studies/nonlin.py   --task ph11
PYTHONPATH=model python attic/studies/contrast.py
PYTHONPATH=model python attic/studies/budget.py   --task ph11
PYTHONPATH=model python attic/studies/synth.py    --task ph11 --split loso --comb 1
```

공유 코드는 `sdcore.py`. 리팩터 후 함수 36개가 원본과 `max|diff| = 0`이고, 로그 숫자 5종이
자릿수까지 재현됨을 확인했다.
